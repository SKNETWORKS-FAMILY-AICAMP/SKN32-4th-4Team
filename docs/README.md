## ★여기 **없는** 것 — 링크가 끊겨 보이는 이유

문서 안에 `../reports/…` · `../plans/…` · `../../CLAUDE.md` 같은 링크가 있는데
**이 저장소에는 그 파일들이 없다.** 일부러 뺐다.

| 안 올린 것 | 왜 |
|---|---|
| `docs/reports/` · `docs/reports/debugs/` · `docs/plans/` | 작업 리포트·디버그 기록. **약관 원문 조각이 인용돼 있다** |
| `docs/review/*.html` (18MB) | 사람 검수 화면. **약관 원문이 그대로 실려 있다** |
| `preprocess_viz.html` · `submission/01_부록_전처리_시각화*.html` | 전처리 시각화. **조항 본문 240자짜리 행이 스크린샷으로 수백 건** 들어 있다 |
| `CLAUDE.md` · `RULE.md` | 내부 작업 규칙. 사내 장비 주소가 적혀 있다 |
| `data/raw/` 약관 PDF · `data/extracted/` 파생 JSON | **저작물** |

★**약관 원문은 저작물이다.** 공개 저장소에 재배포하지 않는다.
실캡처에서도 **인용 본문만 가렸고**(`［약관 원문 272자］`) 조항 ID·약관명·페이지는 그대로 뒀다 —
인용이 동작한다는 증거는 거기에 있기 때문이다.

→ 끊긴 링크는 **누락이 아니라 의도된 제외**다. 내부 저장소에서 원문을 확인할 수 있다.

## 이 문서들이 주장하지 **않는** 것

읽는 사람이 오해하지 않도록 먼저 적는다.

1. **보험금 지급을 확정하는 서비스가 아니다.** 약관 확인을 돕는 **사전판정**이다
2. **확정 문서는 기계 대조까지다.** 사람 최종 승인은 아직 진행 중이다
3. **파인튜닝한 자체 모델은 없다.** `submission/05D` 는 **설계안 + 합성 파일럿**이다
4. **리랭커는 실시간으로 켜져 있지 않다.** 오프라인 release 만 있다
5. 수치를 인용할 때는 **어느 스키마 판(`s5`/`s6`)인지 함께** 적어야 한다 — 분모가 다르다

## 제1원칙

> **모르면 모른다고 한다.**
>
> "보장됩니다"라고 잘못 말하면 사용자가 청구했다가 거절당하거나, 받을 걸 포기한다.
> 그래서 정확도보다 **정직성**이 앞선다.

근거 조항을 못 대면 `verdict="needs_expert"` · `abstained=true` 로 답한다.
이건 오류가 아니라 **정상 결과(HTTP 200)** 다.
