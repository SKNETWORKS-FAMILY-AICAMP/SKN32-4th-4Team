## ★이 제출물이 주장하지 **않는** 것

읽는 사람이 오해하지 않도록 먼저 적는다.

1. **보험금 지급을 확정하지 않는다.** 약관 확인을 돕는 사전판정이다.
2. **확정 850건은 기계 대조까지다.** 사람 최종 승인은 **0건**이다.
3. **파인튜닝을 하지 않았다.** [05D](05D_파인튜닝_모델_설계.md) 는 설계안이다.
4. **리랭커는 실시간으로 켜져 있지 않다.** 오프라인 release 만 있다.
5. **신규 OCR facts 전용 정답셋이 없다.** 측정한 것은 기존 검색 **비회귀**까지다.
6. **커머스 잔재가 남아 있다.** 이 저장소는 쇼핑몰 실습에서 전환 중이다.

## 공개 저장소 주의

- **약관 원본 PDF 와 약관 본문 파생 JSON 은 공개 재배포하지 않는다**(저작물 · `CLAUDE.md` §2).
- 공개 저장소에는 **코드 · 메타데이터 manifest · 스키마 · 평가·무결성 결과**를 올린다.
- 대용량 모델 가중치·임베딩은 Git 이 아니라 **별도 전달 매체나 artifact storage** 로 인계한다.
- 실캡처에서 **약관 인용 본문만 가렸다.** 조항 ID·약관명·페이지는 그대로 뒀다 —
  인용이 동작한다는 증거는 거기에 있다.
