# 테스트 계획 및 결과 보고서

## 1. 목적

보험 약관 사전판정의 핵심 위험은 “서비스가 켜지는가”보다 잘못된 판본·조항·표 값을 확신 있게 반환하는 것이다. 따라서 기능 테스트와 함께 데이터 계보, 검색 품질, 인용 가능성, 사람 승인 경계와 무폴백 동작을 검증한다.

## 2. 테스트 범위와 합격 기준

| 영역 | 검증 대상 | 주요 합격 기준 |
|---|---|---|
| 단위 | 세대, KCD 범위, 조항·표 파서 | 경계값과 오류 fixture 전부 통과 |
| 데이터 품질 | manifest, 문서 수, SHA, 조항·occurrence | 불일치 0, 승인/후보 상태 혼입 0 |
| 검색 | dense, lexical, RRF, parent 복원 | 평가셋 Hit@k·MRR 기준 충족, locator 보존 |
| 리랭커 | 후보 membership, 점수, 순위 | 누락·추가 0, finite·non-constant |
| 판정·인용 | 문서 판본, 기권, citation | 미확정·근거 없음에서 추측 0 |
| API 계약 | REST·MCP 응답, 오류 타입 | schema 일치, 정상 기권과 장애 구분 |
| 보안 | 401/403/200, 라우터 분리, PII | 고객 포트 관리자 경로 404, fail-closed |
| 통합·운영 | DB·index·release·readiness | 활성 release 일치, `ready=true` |
| 성능 | pgvector top20, 리랭커 처리량 | 기준선 대비 비회귀, 측정 환경 기록 |

## 3. 테스트 환경

- Python 3.12, pytest
- 기본 CI: 외부 모델·실 DB 없이 결정론 테스트
- PostgreSQL/pgvector: `pg` marker 별도
- 실제 LLM: `llm` marker 별도
- 무거운 음성·얼굴·임베딩: `ml` marker 별도
- MCP stdio 왕복: `mcp` marker 별도
- 리랭커 실측: RTX 4000 Ada Generation

CI 명령은 다음과 같다.

```bash
pytest -q -m "not llm and not ml and not mcp and not pg and not legacy_data"
```

의존성이 필요한 검사는 분리 실행한다.

```bash
pytest -q -m pg
pytest -q -m llm
pytest -q -m ml
pytest -q -m mcp
```

### 사람 검수

표 후보는 보험사×세대×조판×열 수×성공/실패로 층화한다. 페이지 라벨은 120쪽, 참 37·거짓 83·미결 0으로 병합됐다. S7 facts는 29패턴 전량 검수해 24 approve, 5 fix로 확정했다.

### 제출 문서 링크 계약

제출물은 링크 허브라(`00`→전부, `05`→`05A~05D`) 링크 하나가 죽으면 심사자는 그 항목을
제출하지 않은 것으로 본다. 그래서 기계가 검사한다.

```bash
python -m scripts.verify.check_submission_links     # 13문서 · 상대 링크 94개 · 문제 0
```

`tests/test_submission_links.py` 가 같은 검사를 CI 에서 돌리고,
**커머스 시절 화면(`docs/screen_walkthrough.html`)이 다시 링크되는 것**도 함께 막는다.
