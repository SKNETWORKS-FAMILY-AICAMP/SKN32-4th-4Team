## 5. 실패 대비

| 문제 | 대응 |
|---|---|
| 로컬 LLM 지연 | 미리 warm-up. 그래도 느리면 **컷 5 만 따로 찍어 편집으로 끼운다** |
| 후보가 1개만 나옴 | 계약일이 `20190501` 인지 확인 (다른 날짜면 겹치지 않는다) |
| 근거 0건 | `/api/health/ready` → `vector_index_ready` 확인. 촬영 중 ingest 하지 않는다 |
| 관리자 로그인 실패 | 컷 6 은 **로그인 게이트 화면**이면 충분하다. 안쪽은 원래 안 보여준다 |
| Qwen3 실시간 미동작 | 정상이다. **"실시간"이라고 말하지 않는다** |
| 외부 네트워크 장애 | 로컬 Gemma·PostgreSQL·정적 UI 만으로 촬영 가능하다 |
| 검색 결과가 캡처와 다름 | 입력값·release·모델 프로필을 고정하고 warm query 1회 후 재촬영 |
