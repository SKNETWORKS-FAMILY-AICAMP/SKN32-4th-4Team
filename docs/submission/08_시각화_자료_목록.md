### 1-2. 검증 방법 — 눈으로 보지 않고 잰다

```js
// 브라우저에서 실행 — 모든 도형이 viewBox 안에 있는지, 글자가 겹치는지
svg.querySelectorAll('*').forEach(el => el.getBBox())   // 경계 계산
```

| 그림 | viewBox | 내용 경계 | viewBox 밖으로 | 글자 겹침 | `role`·`aria-label` |
|---:|---|---|---|---|---|
| 1 | 980×400 | 0,0 → 926,354 | 없음 | **0** | ✅ 181자 |
| 2 | 980×470 | 0,0 → 922,462 | 없음 | **0** | ✅ 147자 |
| 3 | 980×400 | 16,11 → 861,375 | 없음 | **0** | ✅ 200자 |
| 4 | 980×430 | 16,11 → 964,410 | 없음 | **0** | ✅ 231자 |
| 5 | 980×400 | 0,0 → 966,382 | 없음 | **0** | ✅ 180자 |

막대 길이도 검산했다 — 그림 3 은 `x = 248 + 비율×6` 이고
`84.71×6 = 508` · `73.47×6 = 441` · `17.35×6 = 104` 로 그려진 값과 일치한다.

> ⚠ **래스터 스크린샷은 찍지 못했다.** 이 세션의 브라우저 패널이 표시되지 않아
> `computer{screenshot}` 이 타임아웃한다. 위 DOM 계측으로 대신했고,
> **사람이 한 번 열어 보는 절차는 남아 있다.**

## 4. ★고친 것 — 전처리 시각화가 「DB 3.5% 적재」로 읽혔다

`01_부록_전처리_시각화.html` §G 는 **손으로 적은 s5 시절 숫자**를 달고 있었다.

```
조항(수록)  전처리 211,131  →  DB 적재 156,946
고유 내용   전처리  63,963  →  DB 적재   2,221
"적재가 중간 상태다. 수록은 74% 들어갔는데 고유 내용은 3.5%뿐이다"
```

그 사이 S7.1 이 적재돼 실제로는 `s6` 발생 **210,733** · 청크 **122,772** 인데,
문서를 여는 사람은 **「DB 가 3.5% 적재됨」으로 읽는다.** 제출물에 그대로 나갈 뻔했다.

**고침**: `scripts/viz/build_preprocess_viz.py` 의 §G 를 **매번 DB 를 조회해 만들도록** 바꿨다.
붙지 못하면 옛 숫자를 채우지 않고 **못 붙었다고 적는다.**

**재생성 후 (2026-08-04 14:17 · DB 직접 조회)**

| 단위 | 전처리 산출(s6) | DB 적재(s6) |
|---|---:|---:|
| 조항(수록) `policy_clause_occurrence` | 204,098 | **210,733** |
| 고유 내용 `policy_clause_content` | 72,723 | 64,607 |
| 청크 `policy_clause_chunk` | — | **122,772** |

`s6` 발생 중 벡터 있음 **190,156** · 인용 가능 **189,890** ·
이전 세대(`s5-mixed`) 158,186 은 게이트 값이 비어 있어 검색에서 막힌다(**누수 0건**, 실측).

§H 의 Tad 캡처는 s5 시절 화면이라 **현재 행 수 표를 캡처 앞에 붙였다**
(`v1` 7 · `v2` 438 · `v3` 2,962 · `v4` 2,843 · `v5` 366).

```bash
# 재생성 (DB 가 떠 있어야 §G 가 채워진다)
python -m scripts.pg status
VIZ_TAG=s6 python scripts/viz/build_preprocess_viz.py
cp docs/handoff/preprocess_viz.html docs/submission/01_부록_전처리_시각화.html
```

## 6. 이 목록이 주장하지 **않는** 것

1. **그림이 판정 정확도를 증명하지 않는다.** 3·4는 **검색 품질**이다.
2. **래스터 스크린샷으로 확인하지 않았다.** DOM 계측(경계·겹침)으로 대신했다.
3. **검수 HTML 3개(18MB)는 발표용이 아니다.** 작업 기록이다.
4. **`01_부록` 의 Tad 캡처는 s5 시절 화면이다.** 행 수는 옆 표를 봐야 한다.
