## 2. 필수 환경

- Python 3.12
- PostgreSQL + `pgvector` + `pg_trgm`
- 로컬 생성 사용 시 llama-cpp-python과 Gemma GGUF
- 충분한 디스크 공간: 원문·구조 데이터·모델·벡터는 Git 외부 artifact 포함
- 실시간 Qwen3 리랭커를 켤 경우 CUDA GPU와 별도 serving 구성

## 3. 설치와 실행

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env
python -m scripts.manage migrate
python -m scripts.pg
python -m scripts.index.build_clause_index
```

> ★`manage` 의 **`seed` 서브커맨드는 더 이상 없다.** 커머스 실습 시절의 시드 CLI 라
> 2026-08-04 에 제거하고 `legacy/v9_commerce_seed_cli.zip` 에 보존했다.
> 현재 서브커맨드는 `migrate · ingest · ready · promote · demote · purge-gaps` 다.
> (이전 판 설치 절차가 없어진 명령을 안내하고 있었다 — 그대로 따라 하면 거기서 멈춘다.)

로컬 답변 모델:

```bash
python scripts/local_model_server.py
```

앱:

```bash
python -m scripts.run_customer_server  # http://127.0.0.1:8080
python -m scripts.run_admin_server     # http://127.0.0.1:8081
```

개발 편의용 통합 앱은 `python scripts/run_dev_server.py`이며 고객 앱과 같은 8080 포트를 쓰므로 동시에 실행하지 않는다.

## 4. 환경 설정

최소 로컬 구성:

```env
LLM_PROVIDER=local
LOCAL_BASE_URL=http://127.0.0.1:8002/v1
LOCAL_MODEL=gemma-4-e4b
LOCAL_API_KEY=not-needed
LLM_CHAT_ENABLED=true
RAG_RERANK_ENABLED=false
```

로컬 모델 주소의 실제 기본값은 `http://127.0.0.1:8002/v1`이다. 8000은 개발 앱 포트이므로 사용하지 않는다. 외부 API를 사용할 때는 `LLM_PROVIDER=openai`와 `OPENAI_API_KEY`, 또는 `LLM_PROVIDER=gemini`와 `GOOGLE_API_KEY`를 함께 설정한다.

`.env`에는 JWT secret, DB 접속정보와 외부 API 키가 들어갈 수 있으므로 Git에 커밋하지 않는다. 외부 OpenAI/Gemini는 선택 사항이며 기본 동작에 필수는 아니다.

## 5. 데이터·모델 artifact 인계

Git만 복제하면 대용량 약관·모델·벡터가 모두 생기는 것은 아니다. 다음을 별도 전달한다.

| artifact | 전달·검증 방법 |
|---|---|
| 약관 PDF | 내부 저장소, 공개 재배포 금지, manifest SHA 대조 |
| s6 구조 데이터 | 압축 artifact, `manifest_s6.json` 대조 |
| Gemma GGUF | 모델 저장소/캐시, 배포 전 SHA-256 기록 |
| Arctic-ko 임베딩 | shard 또는 DB dump, embed model과 dim 검증 |
| S7.1 승인 facts | `data/work/s7_1_approved_facts/`, manifest SHA 대조 |
| 평가·리랭크 release | `data/eval/`, release payload SHA 대조 |

모델 가중치와 임베딩 결과가 Git 파일 몇 개보다 훨씬 큰 것이 정상이다. 저장소에는 재현 코드와 manifest를 두고 대용량 artifact는 별도로 전달한다.

## 8. 운영 규칙

- candidate fact를 파일 복사만으로 accepted로 만들지 않는다.
- 승인 순서는 원문 검수 → 승인 manifest → 청크 → 임베딩 → DB 적재 → 회귀 → release다.
- 임베딩 모델을 바꾸면 기존 벡터와 섞지 않고 새 `embed_model` 공간으로 적재한다.
- 문서 추출 스키마를 바꾸면 새 generation으로 발행하고 현재 검색 필터를 갱신한다.
- Qwen3 실시간 리랭커는 GPU serving·latency·OOM 시험 뒤 `RAG_RERANK_ENABLED=true`로 전환한다.
- model registry의 artifact SHA와 `verified_at`이 비어 있으면 라이브 검증 완료로 취급하지 않는다.
