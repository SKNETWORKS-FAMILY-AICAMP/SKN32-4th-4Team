```

        ↓

                                          ↓
```

> ★**지금 확정 문서가 0건이라 이 파이프라인은 0행을 적재한다.** 버그가 아니다 —
> `policy_version.confirmed_document_id` 가 NOT NULL FK다. 선행 작업은 [02 §0](02_ERD_및_스키마.md).

### 지켜야 할 것

| 항목 | 규칙 |
|---|---|
| 멱등성 | 같은 파일을 두 번 넣어도 행이 늘지 않는다 |
| `excluded_reason` 있는 문서 | **적재하지 않는다** |
| ★식별키 | `UNIQUE(document_extraction_id, ordinal)`. **`qualified_no` 로 UPSERT 하지 않는다** — 문서 내 중복 31,085건 |
| ★`parse_status` 누락 | **`ok` 로 기본값을 주지 않는다.** fail-closed |
| ★`insurer` | `samsunglife` → `삼성생명` 정규화 후 적재. 안 하면 13개사가 된다 |
| ★`page_fallback` | `policy_clause.citeable=false` 로 넣는다. 인용 FK가 막는다 |
| `parse_status != "ok"` | 적재하되 **플래그를 남긴다**. 판정 쿼리에서 뺀다 |
| 실패 | 세어서 보고한다. `except: continue` 금지 |

## 3. API 상태 코드 — **이 구분이 무너지면 안 된다**

| 코드 | 의미 |
|---|---|
| **200** | 판정했다. `abstained=true` (기권) 이어도 200이다 |
| 422 | 입력이 잘못됐다(가입일 형식 등) |
| 503 | 검색·DB 장애. **이때만 우리 잘못이다** |

기권을 503으로 내보내면 클라이언트가 "근거 없음"과 "서버 장애"를 못 가린다.

### 3-1. 조항 의미검색 (`POST /api/admin/clause-search`) — 2026-08-25 추가

| 코드 | 언제 |
|---|---|
| 409 | 리랭킹을 요청했는데 스위치가 꺼져 있다(`INSURANCE_CLAUSE_RERANK_ENABLED=false`) |
| **504** | 리랭킹이 시한을 넘겼다. ★문구가 워커 방식에 따라 **다르다** — `process` 는 「계산이 실제로 멈췄다」, `thread` 는 「아직 돌고 있다」. 같은 말을 하면 거짓이 된다 |
| 503 | 리랭커를 못 띄웠다 · 앞선 시한초과 일감이 아직 도는 중(`thread` 만) |

★**무폴백**: 리랭킹이 실패하면 벡터 순서로 조용히 되돌리지 않는다.
  되돌리면 "재정렬했다"고 믿으면서 실제로는 안 한 상태가 된다.

### 3-2. 사전판정 응답에 늘어난 필드 — `related_clauses` / `related_search`

`/v1/prechecks` 가 벡터 색인을 조회한다(`PRECHECK_RELATED_SEARCH_ENABLED`, 기본 꺼짐).

★★**판정은 바뀌지 않는다.** 결과는 `related_clauses` 로만 나가고 `citations` 에 안 섞인다.
  급도 다르다(`tier="retrieved_clause"`). 화면 규약은 [08_계약_프론트.md](08_계약_프론트.md) §4-2.

`related_search` 가 **세 상태**를 가른다 — `""`(안 함) · `"ok"` · `"failed: ..."`.
검색이 실패해도 **응답은 200 이고 판정은 정상**이다(참고 자료 때문에 판정을 죽이지 않는다).
대신 실패 사실이 `related_search` 와 `warnings` 에 남는다 — 빈 목록으로 숨기지 않는다.

### 3-3. 메트릭 (`GET /api/admin/metrics` · `GET /metrics-scrape`)

Prometheus 노출 형식(`text/plain; version=0.0.4`).

★`/metrics-scrape` 는 **관리자 로그인 밖**에 있다 — 그쪽 의존성을 타면 Prometheus 가 못 긁는다.
  대신 `METRICS_SCRAPE_TOKEN` 이 있어야 열리고, **토큰을 안 정하면 404** 다.
  「설정 안 했으니 열어 준다」가 아니다. 고객 앱에는 안 실린다.
  헤더는 `X-Metrics-Token` 과 `Authorization: Bearer` 둘 다 받는다.
