# 판례·금감원 5인 검토 사용 안내

## 팀원이 할 일

1. ZIP 파일을 새 폴더에 압축 해제합니다.
2. `legal_case_human_review_20260825.html`을 더블클릭합니다.
3. 화면의 `담당 파트`에서 본인이 맡은 1~5파트를 선택합니다.
4. 원문과 AI 정리를 비교해 `맞음`, `수정 필요`, `제외` 중 하나를 선택합니다.
5. `수정 필요`나 `제외`를 선택했다면 이유를 메모에 적습니다.
6. 자기 파트 검토가 끝나면 `현재까지 JSON 내려받기`를 누릅니다.
7. 내려받은 `human_review_queue.json`의 파일명을 `1파트_홍길동.json`처럼 바꿔 총괄 담당자에게 전달합니다.

브라우저를 닫아도 같은 컴퓨터와 같은 브라우저로 다시 열면 작성 내용이 남습니다. 하지만 컴퓨터를 옮길 때는 반드시 JSON을 내려받으세요.

## 총괄 담당자가 할 일

1. HTML을 열고 `팀원 JSON 합치기`를 누릅니다.
2. 다섯 팀원이 보낸 JSON 파일을 한 번에 선택합니다.
3. 전체 진행률이 `114 / 114 완료`인지 확인합니다.
4. 통합 결과를 다시 내려받습니다.
5. 통합 파일을 프로젝트의 `data/legal/human_review_queue.json`에 둡니다.
6. 검토자 이름을 적고 `반영 명령 복사`를 눌러 명령을 실행합니다.

같은 사건에 서로 다른 결과가 들어 있으면 화면에서 충돌 경고가 나옵니다. 경고가 나오면 해당 파트 담당자에게 확인한 뒤 하나로 정리하세요.

## 특별 주의

`case_145`는 4파트에 있으며 원문이 부족합니다. 새 원문을 확보하지 못하면 `제외`를 선택하고 메모에 “원문 부족”이라고 남기는 것이 안전합니다.
