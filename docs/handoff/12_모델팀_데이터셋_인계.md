# 모델팀 인계 — 임베딩용 데이터셋

- 날짜: 2026-08-03
- 만든 것: `data/exports/dataset/` (clauses.jsonl · occurrences.jsonl · manifest.json)
- 재현: `python -m scripts.export.build_dataset --clause-tag s6_pymupdf-1.28.0`

---

## 0. 먼저 알아야 할 것 — **이건 shadow 다**

`manifest.json` 을 열면 이렇게 적혀 있다.

```json
"release_id": "shadow-s6_pymupdf-1.28.0",
"approved_release_id": "r2026-08-02-clause-s5",
"is_shadow": true
```

**승인된 산출물은 `s5` 이고 이 데이터셋은 `s6` 다.** s6 가 s5 보다 낫지만
(부록 분리·참조머리 제거·표 탑재) **사람의 승인 절차를 안 거쳤다.**

그래서:
- **임베딩·평가에는 써도 된다.** 그러라고 만들었다
- **사용자 응답 경로에는 아직 못 쓴다.** 승인 포인터가 s5 를 가리킨다
- 승인이 나면 `config/accepted_extraction.json` 의 `clause_tag` 가 바뀌고,
  그때 `release_id` 가 `shadow-` 없이 다시 발급된다

## 1. 파일 셋

| 파일 | 크기 | 무엇 |
|---|---:|---|
| `clauses.jsonl` | 234 MB | **내용 한 벌.** 중복 제거됨. ★**임베딩 대상** |
| `occurrences.jsonl` | 123 MB | 그 내용이 **어느 문서 어디에** 실렸는가. 근거·인용용 |
| `manifest.json` | 4 KB | 무엇으로 만들었는지 — 세대·규칙 버전·입력 해시·집계 |

### 왜 두 파일인가

같은 조항이 **최대 170개 문서**에 실린다. 중복이 **65.3%** 다.
합쳐서 한 파일로 만들면 본문이 그만큼 늘고, 등장마다 임베딩하면 **같은 계산을 3배** 한다.

```
등장 213,440  →  고유 73,973
```

**`clauses.jsonl` 73,973줄만 임베딩하면 된다.**

## 2. 스키마

### `clauses.jsonl` — 임베딩 대상

```jsonc
{
  "content_hash": "8726c6e5…",   // 식별자. occurrences 와 이걸로 잇는다
  "source_kind": "clause",        // "clause" | "annex"
  "text": "1. (보장종목)\n①회사가…",
  "char_length": 1234,
  "n_occurrences": 17             // 몇 개 문서에 실렸나
}
```

### `occurrences.jsonl` — 근거

```jsonc
{
  "content_hash": "8726c6e5…",
  "sha256": "02aaee47…",          // 원본 문서(약관 PDF)
  "insurer": "DB손해보험",
  "source_kind": "clause",
  "ordinal": 0,                    // 문서 안 순번. 결정적이다
  "occurrence_id": "shadow-s6_…:02aaee47…:clause:0",
  "label": "보통약관/1.",           // 조항이면 조 번호, 부록이면 라벨
  "section": "보통약관",
  "title": "보장종목",
  "page_from": 12, "page_to": 13,
  "eligible": true,                // ★인용 근거로 쓸 수 있나
  "ineligible_reason": "",         // 못 쓰면 왜
  "tables": [ … ]                  // 좌표 복원 표 레코드
}
```

## 3. ★`eligible` — 거르지 않고 이유와 함께 남겼다

**필터는 쓰는 쪽이 정한다.** 임베딩은 전부 하고 인용만 거를 수도 있다.

| | 등장 | 비율 |
|---|---:|---:|
| 전체 | 213,440 | 100% |
| `eligible=true` | **168,517** | **79.0%** |

부적격 사유(상위):

| 사유 | 건수 |
|---|---:|
| 약관 조항이 아니라 **인용 법령** | 29,707 |
| 인용 부적격(조 경계 모순) | 7,677 |
| 문서 파싱 상태가 `suspect` | 7,101 |

> ★「인용 법령」은 약관 뒤에 실린 상법·의료법 조문이다. 그대로 인용하면
> **"단체취급 특별약관 제651조(고지의무위반…)"** 같은 근거가 나간다 — 출처가 틀린다.

판정 규칙은 `app/core/domain/eligibility.py` 한 곳이고 버전은 `elig-1` 이다.
`manifest.json` 에 그 버전이 박혀 있다.

## 4. ★부록은 조가 아니다

`source_kind="annex"` 인 것 **9,342건**이 별표·붙임·장해분류표다.
**KCD 대조의 실제 근거가 여기 있다.**

- 인용은 `label`(`[별표1] 특정질병 분류표`)로 한다
- **조 번호로 인용하면 출처가 틀린다** — `제27조(준용규정)에 따르면 분만은 O80~O84`
- 부록에는 `citation_eligible` 이 없어서 `parse_status` 만 본다

## 5. 표(`tables`) — **일부만 실려 있다**

| | |
|---|---:|
| 실린 표 | **고유 613개** (부착 1,313회) |
| 그 레코드 | 고유 8,849 |
| **미검증이라 보류** | **109,192개** |

좌표 복원이 두 경로인데 **선(벡터 괘선)** 경로만 실었다.
`2열짝짓기` 경로는 열었다가 통과분의 **80%가 본문 두 단 조판**이라 다시 닫았다.

정답셋은 **흥국화재 한 조판 66레코드**뿐이고 거기서 도달률 1.000·오짝 0이다.
**그 66레코드를 전체 정확도로 읽으면 안 된다.**

## 6. 품질 — 아는 것과 모르는 것

### 실측한 것

| | 값 |
|---|---|
| 문서 | 1,367 (ok 1,306 · suspect 52 · no_clause_heads 9) |
| s5↔s6 정합 검사 28종 | **확정 위반 0건** |
| 표 도달률(정답셋 66레코드) | 1.000 · 오짝 0 |
| 인용 쪽(`page_from`) 적중 | 0.98492 · **불일치 0** |
| 면책 recall@5 (낱말검색 baseline, 타사표현) | 0.3947 |

### **모르는 것**

- **표 109,192개가 진짜 표인지** — 보류 상태다
- **부록 recall** — "덜 삼켰다"만 알고 "다 찾았나"는 모른다
- **조 경계 정확도** — 구조 결함 S1 4,613건·S2 27,602건의 원인이 미규명이다
- 정답셋이 **한 조판**뿐이다

> `96.10%`·`79.0%` 같은 수치는 **"게이트 통과율"이지 "정확도"가 아니다.**

## 7. 임베딩할 때 주의

1. **모델을 아직 안 정했다.** 이 데이터셋에 벡터는 없다.
   벤치마크는 나와 있다 → `docs/reports/2026-08-02_1800_임베딩모델_후보_20선_코덱스합의.md`

   | 모델 | maxlen | 절단 | R@10 | **단서맹** |
   |---|---:|---:|---:|---:|
   | nlpai-lab/KURE-v1 | 8192 | 0% | 0.724 | **0** |
   | dragonkue/snowflake-arctic-embed-l-v2.0-ko | 8192 | 0% | 0.703 | **0** |
   | jhgan/ko-sroberta-multitask (옛 기본값) | **128** | **83.7%** | 0.607 | **35** |

2. ★**`max_seq_length` 를 반드시 확인해라.** 옛 기본 모델이 128토큰에서 잘랐고
   조각의 **89.1%** 가 잘린 채 임베딩됐다. 면책은 문장 끝에 오므로
   (`…보상합니다. 다만 … 보상하지 않습니다`) **면책이 벡터에서 사라진다.**
   실측: 면책 문장을 붙인 것과 안 붙인 것의 코사인 유사도 **1.000000**.

3. 조항 길이가 길다. 중앙값 613자 · 99분위 14,200자 · 최대 29,864자.
   조각내야 하면 **문장 경계**로 끊어라 — 법률문은 예외가 문장 끝에 온다.

4. 프로필을 기록해라 — 모델·revision·차원·`max_seq_length`·청킹 예산·겹침.
   이름만 같고 설정이 다르면 벡터 공간이 달라진다.
