## 0. 세 줄 요약

1. **Django 는 「말단 전달 계층」에만 적용했다.** 판정·검증·검색·인용은 FastAPI 그대로다.

## 2. ★지금 Django 가 적용된 영역 (정확히)

```
브라우저 ──→ Django (전달 계층)  ──→ FastAPI (코어)
              │                        │
              │ 세션·CSRF·보안헤더      │ 스키마 검증·판정·검색·인용·AI
              │ Admin(/admin/)         │ 정적자산(/static/)
              │ 화면 통과              │ OpenAPI
              └ 가공 없이 전달 ────────┘
```

### Django 가 **처리하는** 것

| 경로 | 무엇 |
|---|---|
| `/admin/` | Django Admin (모델 1개 — `DeliveryAuditLog`) |
| `/delivery-static/` | Admin 의 CSS·JS |
| **그 외 전부** | FastAPI 로 **가공 없이 전달** |

전 요청에 붙는 것: 세션 · CSRF · 보안 헤더(`X-Content-Type-Options`·`X-Frame-Options`·`Referrer-Policy`) · `X-Trace-ID` 승계/발급

### Django 가 **절대 안 하는** 것

스키마 검증 · 응답 직렬화 · 도메인 오류 본문 생성 · 판정 · AI · 검색 ·
`app.core`/`app.workflow`/`app.routers` import

★**말로만 두지 않았다.** `tests/delivery/test_django_import_boundary.py` 가
**AST 로 검사**한다 — 도메인 구현을 import 하면 테스트가 깨진다.

### ★왜 이렇게 좁게 잡았나

처음 계획(v1)은 **엔드포인트를 Django 로 포팅**하는 것이었고 **폐기했다.**
그대로 갔으면 FastAPI 가 공짜로 주던 것(pydantic 검증 · `response_model` 직렬화 · OpenAPI)을
Django 에 **다시 구현**해야 했다. 그 순간 **판정 규약이 두 벌**이 된다.
두 벌이면 반드시 어긋나고, 어긋나면 **「보장됩니다」를 잘못 말한다**(`CLAUDE.md` §0).

## 3. 이대로 유지할 때 — 얻는 것과 잃는 것

### 얻는 것

| | 무엇 | 실증 여부 |
|---|---|---|
| ★ | **세션 + HttpOnly 쿠키** 기반 인증 자리 | 구조만 준비. 제품 화면에 로그인이 아직 없다 |
| ★ | **CSRF 보호** | ✅ 동작 확인 |
| | **기본 보안 헤더** (`nosniff`·`X-Frame-Options`·`Referrer-Policy`) | ✅ 패스스루 응답까지 도달 확인 |
| | **Admin** — 운영 화면 | ✅ 동작 + **대가까지 실측**(아래) |
| | 템플릿·정적 자산 관행 | 화면이 늘면 이득이 커진다 |
| | `check --deploy` 같은 배포 점검 | ✅ 경고 5건 → 2건 |

### 잃는 것 / 대가

| | 무엇 | 크기 |
|---|---|---|
| | 홉 하나 고정비 | **+1.4~3.8 ms** (`noop` 기준) |
| | **실제 판정 경로** 비용 | **+0.9~1.8 ms (+2.7~9.1%)** — 세 기계 모두 사전 기준(10%) 안 |
| | Admin 을 켠 대가 | **−0.11 ms(noop) / +0.57 ms(판정)** — ★구간이 겹쳐 **구별되지 않음** |
| | 프로세스·배포 대상 +1 | 컨테이너 1개, 헬스체크 1개 |
| ★ | **CSRF 가 비브라우저 클라이언트를 막는다** | curl·부하도구·모바일이 토큰을 먼저 받아야 한다 |
| ★ | 설정 이원화 위험 | `ALLOWED_HOSTS` 를 파생시켜 막았고, 공개 도메인은 `DELIVERY_ALLOWED_HOSTS` 로 명시 |

### ★그래서 결론

**성능은 이 결정의 근거가 되지 못한다.** 세 기계에서 전부 기준 안이다.
결정은 **얻는 것**으로 한다 — 세션 보안 · Admin · 화면 관행.

★단서 하나: **분모가 작아지면 비율은 커진다.** 판정 경로를 더 빠르게 만들면
전달 비용의 비중이 올라간다. 그때 다시 재야 한다.

★비교 대상 하나: **커넥션 풀 부재가 +21.6 ms(+231%)** 다 — 전달 계층 비용의 **23배**.
성능을 논한다면 전달 계층이 아니라 **거기**를 봐야 한다.

## 4. ★언제든 FastAPI 로 되돌릴 수 있게 해 둔 것

### 스위치 하나

```bash
DELIVERY_MODE=direct    # 브라우저 → FastAPI            (전환 이전과 동일)
DELIVERY_MODE=django    # 브라우저 → Django → FastAPI   (지금 형상)
```

★**알 수 없는 값이면 기동이 실패한다.** 조용히 `direct` 로 떨어지지 않는다 —
그러면 「Django 를 켰다고 생각했는데 안 켜진」 상태를 아무도 모른다.

compose 도 같은 변수 하나를 본다:

| 값 | `delivery` 컨테이너 |
|---|---|
| `direct` | **exit 0** 으로 정상 종료 (FastAPI 단독) |
| `django` | Django 기동 |
| 그 외 | **exit 64** — 실행 검증 완료 |

### 되돌릴 수 있게 만든 다른 것들

| | 무엇 |
|---|---|
| **의존성 분리** | `requirements/delivery.txt` 는 **루트 집계에 없다.** FastAPI 단독으로 돌리는 사람에게 Django 를 강요하지 않는다 |
| **이미지 분리** | Dockerfile 의 `INSTALL_DELIVERY` build arg. 기본 `false` — `customer`·`admin`·`migrate` 이미지에 Django 가 **안 들어간다** |
| **코어 무수정** | FastAPI 쪽 판정 코드는 이 전환으로 **바뀌지 않았다**. `delivery/` 를 지우면 그대로 원상복구다 |
| **테스트 격리** | `tests/delivery/` + `delivery` 마커. 기본 CI 에서 제외되므로 전환 작업이 주 회귀검사를 흔들지 않는다 |
| **경계 자동 검사** | 도메인 구현을 import 하면 **테스트가 깨진다**. 「나중에 조금만」이 쌓이는 것을 막는다 |

### 관련 설정 전량

```
DELIVERY_MODE                 direct | django          전환 스위치
DELIVERY_DJANGO_BASE_URL      http://127.0.0.1:8000    ★ALLOWED_HOSTS 가 여기서 파생된다
DELIVERY_ALLOWED_HOSTS        ""                       공개 도메인 뒤에 둘 때 명시(없으면 400)
DELIVERY_SECURE_COOKIES       false                    HTTPS 배포에서 true
DELIVERY_UPSTREAM_KEEPALIVE   true                     측정용 대조군 스위치
BENCH_ENDPOINTS_ENABLED       false                    /_bench/* 마운트 여부
```

## 6. 사람 판단이 필요한 것

| | 무엇 | 왜 |
|---|---|---|
| ① | **W3 세션 브리지 재정의** | 제품 화면(`insurance.html`)은 **localStorage 토큰을 애초에 안 쓴다.** 그걸 쓰는 `admin.html`·`mypage.html` 은 **삭제 예정 커머스 잔재**다. 지울 화면을 위해 세션 브리지를 세우는 것은 값이 없다 |
| ② | **B 형상(Django 경유)으로 공개할 것인가** | 성능은 중립. 보안·운영 이득으로 판단 |
| ③ | **EC2 배포 방식** | 접근 수단을 주실지, 배포 스크립트를 받으실지 |
| ④ | TLS·도메인 | EC2 용 이름이 따로 필요하다(`jikimi.duckdns.org` 는 x600 용) |

## 7. 이 문서가 말하지 않는 것

- **pgvector 판정 경로는 미측정이다.** 판정 측정은 전부 `CLAUSE_STORE=file` 기준이다.
  x600 색인으로 재려 했으나 **마이그레이션 020 미적용**으로 503 이 난다(다른 세션 진행 중).
- **엣지 프록시·TLS 는 없다.**
- **회차 5 — 표본이 작다.** 절대값은 못 쓰고 구성 간 차이만 유효하다.
- **실제 컨테이너 build/up 은 검증하지 못했다** — 이 환경에 Docker 가 없다.
