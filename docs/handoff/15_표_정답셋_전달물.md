## 1. ★먼저 — `s5` 가 맞습니다 (`s6` 아님)

헷갈리기 쉬운 지점이라 먼저 적는다. **`s5`/`s6` 는 버전이 아니라 서로 다른 단계다.**

```
data/extracted/   (페이지 JSON)   s1 s2 s3 s4 s5        ← ★s6 가 없다
data/structured/  (조항 JSON)     s1 s2 s3 s4 s5 s6
```

| | 들어 있는 것 |
|---|---|
| `extracted/s5` 페이지 키 | `page` · `text` · `tables` · **`tables_coords`** |
| `structured/s6` 조항 키 | … `tables`(그 조항에 실린 표) — **좌표·method·T1~T5 signals 없음** |

표 좌표와 신호는 **페이지 단계 산출물**이고, s6 는 **조항 구조화 단계**에서 바뀐 것이라
페이지를 다시 뽑지 않고 s5 페이지를 그대로 입력으로 쓴다.
→ `build_table_labelset.py` 가 `extracted/*/s5_*` 를 읽는 것은 **의도된 동작**이다.

★같은 `sN` 접두어를 두 단계가 공유해서 "s6 가 더 최신"으로 읽히는 것은 **네이밍 문제**다.
단계별 카운터가 독립이라는 사실을 알고 봐야 한다.

## 4. A 작업 — 참/거짓 후보 60건

`table_tf_candidates.json` 에 **경로별로 30건씩** 담았다.
★**키 이름을 일부러 "참/거짓"이 아니라 경로 이름으로 뒀다** — 15번 문서 경고대로
자동값을 미리 넣으면 그걸 따라 찍게 되기 때문이다.

| 키 | 뽑은 기준 | 주의 |
|---|---|---|
| `line_method` | 「선」 경로 · 5행 이상 (전체 813건 중 30) | ★**선 경로에도 과탐이 있다** — 아래 |
| `overdetect_suspect` | 「2열짝짓기」 · `T1_corridor ≤ 0.046`(하위10%) · (`T4_sentence ≥ 0.6` 또는 `T5_fragment ≥ 0.25`) (3,055건 중 30) | 전형적 과탐이 많이 잡힌다 |

### ★「선이면 진짜 표」라고 전제하지 마세요 — 실측

`line_method` 첫 건(`dbins` p4, 13행)을 열어 보면 이렇다:

```
{'1': '약관의 핵심 핵심사항 등과', '2': '체크항목 쉽게찾기(보통약관기준) 관련된 해당 조문, 쪽수 …'}
```

**안내 페이지의 다단 조판이 격자로 잡힌 것**으로 보인다. 즉 「선」 경로도 검증 대상이다.

### 그리고 「선」 경로는 신호가 아예 없다

```
선          813건   is_table = None (813건 전부) · T1~T5 없음
2열짝짓기  109,421건  is_table = True 15,687 / False 93,734 · T1~T5 있음
```

**선 경로는 신호를 계산하지 않는다.** 그래서 신호로 걸러낼 수 없고, 사람이 봐야만 한다.
→ A 작업에서 「선」 쪽 라벨이 특히 값어치가 크다.

## 8. ★"셀이 잘린다" — 해결했습니다 (2026-08-03)

### 셀을 자르지 않습니다

```jsonc
"preview": [ { "1": {"len": 5,   "text": "입원제비용"},
               "2": {"len": 130, "text": "입원치료 중 발생한 진찰료, 검사료, …"} } ]
```

처음엔 60자, 다음엔 400자로 잘랐는데 **"내가 자른 것"과 "데이터가 깨진 것"이 헷갈렸다.**
전문으로 바꿔도 +5KB 뿐이라 **자르기를 없앴다.** 최장 셀 895자.
`len` 은 남겼다 — 길이 자체가 판단 재료다(짧은 항목명 vs 긴 설명).

### ★잘려 있어도 표로 보이면 `table` 로 찍으면 된다

라벨은 **"이 표가 진짜 표인가"** 를 묻는 것이지 셀이 완전한지를 묻는 게 아니다.

| 상황 | 판단 |
|---|---|
| 보이는 부분만으로 **격자 구조가 분명**(항목명 \| 설명) | **`table`** — 뒤가 어떻든 상관없다 |
| **어절이 열 사이로 흩어져** 말이 안 된다 | **`prose`** — 이게 과탐의 결정적 증거 |
| 보이는 것으로 판단이 안 선다 | **`unsure`** — 억지로 고르지 마세요 |

★**자르기는 거짓 판단을 방해하지 않는다.** 보이는 부분에서 이미 어절이 흩어져 있으면 그게 증거고,
자르기는 증거를 *더 가릴* 뿐 **없는 증거를 만들지는 않는다.**

**`prose` 실례** (`dbins` p73):
```
[1] "19의2. 킬로미터 30킬로그램"
[2] "이동장치”란 … 시속 25 운행할 경우 … 차체 중량이 것으로서 …"
```

원문은 **"시속 25킬로미터"** · **"차체 중량이 30킬로그램"** — 숫자 뒤 단위가 왼쪽 열로 떨어졌다.

**`table` 실례** (`dbins` p54 용어정의표, T1=T4=T5=0):
```
[1] "입원제비용"
[2] "입원치료 중 발생한 진찰료, 검사료, 방사선료, 투약 및 처방료(…), 주사료, …"   (130자, 문장 완결)
```
