이 그림에서 읽어야 할 세 가지
  • POLICY_VERSION → CONFIRMED_POLICY_DOCUMENT 가 NOT NULL FK — 확정 안 된 문서로는 약관 버전 행 자체를 만들 수 없다
  • ASSESSMENT_CLAUSE_CITATION 의 FK가 POLICY_CLAUSE 하나뿐 — 로그·FAQ·외부 보고는 넣을 수 없다
  • INTERACTION_LOG 에 core 로 가는 FK가 없다 — 상호작용 기록이 판정 근거로 승격되지 않는다
