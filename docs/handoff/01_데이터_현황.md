## 6. 판매시점 신뢰도

| 등급 | 뜻 | 처리 |
|---|---|---|
| `exact` | 사이트·URL·표지에 날짜가 **적혀 있다** | 그대로 쓴다 |
| `month` | 상품코드에서 **월까지만** 유도했다 | 세대 판정엔 충분. 경계달이면 `ambiguous` |
| (없음) | 원래부터 있던 값 | 수집 당시 사이트 값 |

날짜를 끝내 못 찾은 것은 **4건**이다(제도성 특약 — 자체 판매기간이 없는 문서).

**결정적 단서는 URL이었다.** 삼성생명 약관 URL 경로에 판매개시일이 박혀 있다:
```
/uploadDir/doc/2021/0401/LP0525006/…   →  2021-04-01
```
사이트에서 직접 읽은 40건과 대조해 **40/40 일치**를 확인한 뒤 173건에 적용했다.

## 9. 공유 가능 여부

| 자료 | 팀 내부 | 외부·공개 저장소 |
|---|---|---|
| **매니페스트** `data/raw/manifests/*.jsonl` | ✅ 가능 | ⚠ 출처 URL 포함. 공개 무방하나 팀 합의 후 |
| **조항 JSON** `data/structured/` | ✅ 가능 | ❌ 약관 원문 파생물이다 |
| **약관 PDF** `data/raw/insurance_terms/` | ✅ 가능 | ❌ **재배포 금지** |
| 수집·전처리 스크립트 | ✅ | ✅ |

매니페스트는 **메타데이터만** 담는다(보험사·상품명·판매기간·URL·해시).
약관 본문은 들어 있지 않으므로 팀 공유에 문제가 없다.

> 다만 조항 JSON은 **v4 기준으로 다시 뽑은 것**을 써야 한다.
> v2·v3 산출물은 목차 오인·번호체계 오판 결함이 있다.
