단순 자동 생성으로 단정할 직접 증거는 없었다. 파일 순서상 이전 항목으로 돌아간 흔적이 9회이고 작업 간격도 일정하지 않았다. 반면 표의 행·열 관계를 판정하는 기준을 반복해서 잘못 적용해 내용 검수는 통과하지 못했다.

원본 대조로 확인한 20건은 조항 밖 페이지 1건, 표 A 4건, 표 B 15건이다. JSONL은 아직 수정하지 않았고 통합 기록에 `수정 대기`로 남겼다.

## 4. 검증 방법

- Part 1 JSONL과 `docs/handoff/review_600_5parts/part1.html`의 `review_id` 전수 대조
- PowerShell `ConvertFrom-Json`으로 142행 전수 파싱
- 제출 시각 정렬, 작업 구간, 선택 분포, 제안 일치율 계산
- `data/raw/insurance_terms/**/*.pdf` 원본 페이지 시각 대조
- Poppler `pdftoppm`이 설치되어 있지 않아 PyMuPDF 1.28 계열로 페이지를 PNG 렌더링해 확인
- Part 2·5는 `backup/20260826_0421_정정전/`과 현재 파일을 ID별 비교
