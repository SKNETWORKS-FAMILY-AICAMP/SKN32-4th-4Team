## 8. 22:41 선택 표시·저장값 버그 수정

사용자 화면 확인에서 버튼을 눌러도 카드 외곽선만 초록색이 되고 선택한 버튼은 표시되지 않는 결함을 확인했다.

- 원인: 선택지 반복문의 `label` 변수에 화면용 한글 문구가 들어 있었는데, 클릭 시 내부 코드인 `value`가 아니라 이 한글 문구를 저장했다. 이후 화면은 저장값과 버튼의 내부 코드를 비교했으므로 어느 버튼도 선택 상태가 되지 않았다.
- 수정: 저장값을 `label:value`로 바꿨다.
- 표시: 선택 버튼에 `✓ 선택됨` 문구, 진한 배경·굵은 테두리를 추가하고 버튼 위에 `✓ 현재 선택: …` 요약을 표시한다.
- 접근성: 각 버튼의 `aria-pressed` 값을 실제 선택 상태와 동기화한다.
- 기존 작업 보존: 종전 버그로 저장된 한글 선택 문구는 새 HTML을 열거나 결과 JSONL을 불러올 때 내부 코드로 자동 변환한다. 알 수 없는 값은 완료로 세지 않고 다시 선택하라는 경고를 표시한다.
- 안내 페이지 보강: `보험약관이란`, QR코드, 약관해설 영상, 보험금 지급절차처럼 안내 신호가 여러 개 나오면 `표지·목차·안내문`을 제안하도록 했다. 사용자 사례 `ca25446de298` p.3은 새 생성물에서 이 선택지로 제안된다.
