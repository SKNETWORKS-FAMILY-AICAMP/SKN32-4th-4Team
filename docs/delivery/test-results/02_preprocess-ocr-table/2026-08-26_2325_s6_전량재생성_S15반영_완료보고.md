5. `manifest_s6.json` 을 재기준선화 **전**에 백업(`data/backup/

## 3. 알려진 잡음(막지 않음) — manifest 재기준선화 중 코덱스 무관 스레드 예외

`build_manifest.py --force`/`--verify` 둘 다 실행 중
`UnicodeDecodeError`(`Thread-5 (_readerthread)`)가 콘솔에 찍혔다 — 매니페스트가
버전 스탬프용으로 부르는 `git status`/`diff` 서브프로세스가, 이 저장소가
**여러 프로젝트를 함께 담은 공유 워킹트리**(동시 세션 다수 활성, PDF 등
바이너리 파일도 dirty 상태로 섞여 있음)라 출력에 UTF-8 이 아닌 바이트가
섞여 생긴 것으로 보인다. **기능적으로는 영향 없음** — 두 명령 다 exit 0,
`--verify` 는 "어긋남 0"으로 정상 종료했고, 매니페스트 JSON 자체도 유효하다
(`documents`/`counts`/`problems` 필드 정상 로드 확인). `code.dirty_files`
목록이 이 저장소 전체의 커밋 안 된 변경분(다른 프로젝트 포함)을 그대로
담고 있어 매우 길다 — 참고용 메타데이터일 뿐 무결성 검증(`--verify`)의
근거가 아니므로 그대로 둔다.
