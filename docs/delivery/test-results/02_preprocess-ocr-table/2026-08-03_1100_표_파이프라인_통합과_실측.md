## 0. 무엇이 문제였나

`table_coords.py`(좌표 기반 표 복원)는 정답셋에서 **F1 1.000** 이었다.
그런데 **부르는 곳이 평가 스크립트뿐이었다.** 판정이 실제로 읽는 것은
PyMuPDF 가 뱉은 평평한 텍스트였고, 그게 맞는지는 **한 번도 재지 않았다.**

재보니 **0.455** 였다. 질병명↔KCD 코드 짝의 절반 이상이 틀린다.

> "표 작업을 했다"와 "표가 판정에 도달한다"는 다른 말이다.
> 이 프로젝트가 이미 데인 실패 유형이다 — `to_clauses.py` 독스트링이
> 9단계를 "하는 일"로 적어 놓고 하지 않았던 것과 같다.

## 2. 고친 곳 셋

### 2-1. 2열 표가 `records` 를 안 만들어 전부 버려졌다

`table_coords.extract()` 의 "선" 경로만 `records` 를 만들고 "2열짝짓기" 경로는 안 만들었다.
페이지 JSON 쪽 필터(`if not t.get("records"): continue`)가 그걸 전부 떨어뜨려
**문서당 좌표 표가 1개**만 남았다. 2열에도 레코드를 만들자 **100개**가 됐다.

★2열은 번호 anchor 가 없어 `no` 가 **행 순서**다. 원문 번호가 아니다.
그래서 `no_source: "row_order"` 로 밝힌다 — 지어낸 값처럼 보이면 안 된다(§1).

### 2-2. 페이지 JSON 에 `tables_coords` 추가 (s4 → **s5**)

- `tables`(find_tables 결과)는 **안 지웠다.** 좌표 복원이 실패한 페이지에서
  무엇을 잃었는지 알려면 두 벌이 필요하다(CLAUDE.md §1).
- `grid` 는 안 싣는다 — `records` 에서 복원되고, 전량이면 수 GB 다.
- 실패 페이지는 `tables_coords_failed_pages` 에 **사유와 함께** 남는다(§3).

### 2-3. 조항·부록이 `tables[].records` 를 실어 나른다

부록 쪽이 **KCD 대조의 실제 근거**다 — 질병분류표·장해분류표가 전부 거기 있다.
표는 페이지 단위라 조 경계보다 넓을 수 있어 `page` 를 붙인다.
조 안의 어디인지까지는 **모른다. 추정하지 않는다.**

## 3. 실측

### 도달률

```
조항 JSON 도달 짝 정확도 66/66 = 1.000
  이름 못 찾음 0 · 오짝 0
```

**오짝 0** 이 핵심이다. `심장질환 → I60~I69`(뇌혈관 것) 같은 오짝이
이 서비스에서 가장 위험한 실패인데, 그게 사라졌다.

> ★처음엔 60/66(0.909) 이 나왔다. 원인은 **측정 버그** —
> 정답 이름에서만 쉼표를 지우고 레코드 쪽은 안 지워
> `관절병증, 연골병증` 이 "못 찾음"으로 찍혔다. 실제로는 실려 있었다.
> 양쪽에 같은 정규화를 걸어 고쳤다.

★원격에는 DB 자격증명도 매니페스트도 보내지 않는다. 들어가는 것은 PDF, 나오는 것은 페이지 JSON 이다.

## 7. ★정정 (2026-08-03 추가) — §3 「전량」의 표 수치는 **부착 횟수**였다

**원문은 위에 그대로 둔다.** 무엇이 틀렸었는지가 기록으로 남아야 한다.

### 무엇이 틀렸나

§3 「전량」의 `표 405,845개` · `레코드 2,549,729개` · `표를 실은 조항·부록 193,783` 은
**서로 다른 표의 개수가 아니라 조항·부록에 붙은 횟수**다. 세던 코드가 이랬다.

```python
for k in ("clauses", "annexes"):
    for x in doc[k]:
        for t in x.get("tables") or []:
            T += 1          # ← 부착 횟수. table_id 중복 제거가 없다
```

한 표가 조항과 부록에 둘 다 붙으면 2로 센다. 표는 **페이지 단위**라 조 경계보다 넓고
(§2-3), 그래서 여러 조항에 걸쳐 붙는다 — 부풀림이 구조적으로 생긴다.

경위와 위험도: 디버그 리포트 (내부 원본 참조: `debugs/2026-08-03_표_개수를_부착횟수로_보고.md`)

| 항목 | §3 에 적힌 값 | 2026-08-03 실측 | 단위 |
|---|---:|---:|---|
| 조항·부록에 실린 표 | 405,845 | **613** | **고유** (부착은 **1,313회**) |
| 그 레코드 | 2,549,729 | **8,849** | **고유** (부착은 **18,127**) |
| 표를 실은 조항·부록 | 193,783 | **1,206** | 조항 190 + 부록 1,016 |

★**두 값은 같은 파이프라인을 잰 것이 아니다.** 405,845 는 `2열짝짓기` 를 포함해
**전부 싣던 때**의 부착 횟수이고, 613 은 `선` 경로만 싣는 게이트가 들어온 뒤의 고유 수다.
그러니 "405,845 → 613" 은 한 가지가 아니라 **두 가지가 겹친 차이**다 —
(1) 부착→고유 단위 정정, (2) 미검증 경로를 보류로 뺀 게이트.
