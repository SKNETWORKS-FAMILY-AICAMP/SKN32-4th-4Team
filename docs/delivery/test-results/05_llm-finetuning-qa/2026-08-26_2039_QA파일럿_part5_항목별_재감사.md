## A축 36건

- 사고일이 가입일보다 앞선 항목: 0건
- 직접 근거가 있는 항목: 13건
- 인용 게이트 `parse_status=ok`, `citation_eligible=true`: 13건 모두 통과
- `exception_applies`는 KCD 범위 스캐너로 예외 관계를 확인
- `excluded_by_clause`는 면책 관계 또는 `보상하지 않는 사항` 제목과 코드 직접 언급을 확인
- 인용 0건 기권 항목 23건은 판정은 유지하고 고객 문장만 수정

직접 근거 13건 중 3건은 인용문이 목록 중간에서 잘려 면책 선언의 순서를 스캐너가 완전히 복원하지 못했습니다. 이 3건은 `보상하지 않는 사항`이라는 조항 제목, 인용 가능 게이트, 해당 KCD 코드의 직접 등장을 함께 확인해 승인했습니다. 이 보조 판정도 `audit_checks`에 표시했습니다.
