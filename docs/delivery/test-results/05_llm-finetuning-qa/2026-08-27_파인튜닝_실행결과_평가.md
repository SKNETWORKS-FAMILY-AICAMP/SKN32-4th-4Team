# 파인튜닝 실행 결과 — gemma-4-E4B-it QLoRA · gold 221건 평가

날짜 2026-08-27 · 계획 2026-08-27_파인튜닝_실행과_평가_계획 (내부 원본 참조: `../plans/2026-08-27_파인튜닝_실행과_평가_계획.md`) · 설계 05D (내부 원본 참조: `../submission/05D_파인튜닝_모델_설계.md`)

## 0. 한 줄 결론

**어댑터를 붙인 모델은 돌아가고, 추론이 12GB 에 들어가며, 고객 문장의 형식 결함이 27.6% → 0% 로 줄었다.**
단, **정확도가 좋아졌다고는 말할 수 없다** — 학습 라벨의 85%가 사람이 안 본 규칙 라벨이고,
`groundedness` 는 재지 않았다.

## 2. ★배포 가능성 — **추론은 12GB 에 들어간다**

학습 peak 과 추론 peak 은 다른 값이다. 05D §5 가 예산을 잡은 대상은 학습이었지만,
**배포에 필요한 것은 추론 쪽**이다.

| | baseline | 어댑터 | 차이 |
|---|---|---|---|
| 가중치만 | 8.66 GiB | 10.87 GiB | +2.21 |
| **추론 peak** | **8.81 GiB** | **10.97 GiB** | **+2.16** |
| **12GB 진입** | ✅ | ✅ | |

★**§12-3 의 기각 사유 3 은 학습 기준이었다.** 서빙만 보면 12GB 카드에서 돈다.
그리고 §12-3 이 원인으로 지목한 `prepare_model_for_kbit_training()` 은 **틀린 지목**이었다 —
그 함수를 빼고도 학습 peak 이 16.39GiB 였다. 진짜 병목은 **어휘 262k × seq 2048 로짓 텐서**다
(실제로 평가 batch 8 에서 `cross_entropy` 가 4.64GiB 를 요청해 OOM 났다).

★**둘을 갈라 읽어야 한다.** 지연이 46% 줄어든 것은 **출력이 짧아졌기 때문**(89.3 → 37.3 토큰)이고,
어댑터 자체 비용은 **토큰당 +29.1%** 다.

★이 값이 §12-2 의 실측(**토큰당 +26.9%**)과 거의 같다. 다른 데이터·다른 GPU 에서 잰 값이
비슷하게 나온 것이므로, **토큰당 +27~29% 가 어댑터의 고정 비용**이라고 볼 근거가 생겼다.
지난번은 출력이 길어져서(+31%) 총 지연이 늘었고, 이번은 짧아져서 줄었다 —
**총 지연은 그 실험의 출력 길이에 묶여 있다.**

## 5. ★나빠진 것 — 반복 출력이 늘었다

| | baseline | 어댑터 |
|---|---|---|
| 반복 출력(같은 18자 조각이 3회 이상) | 13/221 (6%) | **27/221 (12%)** |
| 축별 | D 13 | **D 25** · C 2 |

```
어댑터(D축): … 면책 조건을 확인한 조항과 일치합니다. — 같은 조항에서 면책 조건을
             확인한 조항과 일치합니다. — 같은 조항에서 면책 조건을 확인한 조항입니다. — 같…
```

**D축이 학습에 실패했다고 봐야 한다.** 유사도도 0.157 로 거의 안 올랐다.
D 는 「이 조항이 근거로 맞나」라 정답이 **조항 원문 발췌**인데, 그건 생성으로 배울 것이 아니다.
D축은 학습 대상에서 빼고 **근거 적합성 분류**로 따로 다루는 것이 맞다.

## 6. ★이 결과를 어떻게 말해야 하나

**말할 수 있는 것**

- 어댑터를 붙인 모델이 **동작하고 추론이 12GB 에 들어간다**
- 고객 문장의 **형식 결함이 사라졌다** — 내부 필드명 노출 27.6% → 0%
- 두 지표 다 **95% 구간이 0 을 걸치지 않는다**
- 어댑터의 고정 비용은 **토큰당 +29%**, §12-2 와 재현된다

**말할 수 없는 것**

- **정확도가 좋아졌다** — 학습 라벨의 85%가 사람이 안 본 규칙 라벨이다
- **`groundedness`** — 주장이 근거로 검증되는지는 재지 않았다(사람 검수로만 나온다)
- **규칙 위반 0 이 대단하다** — 학습 라벨을 만든 규칙과 평가 규칙이 **같다.**
  값은 오히려 **baseline 이 27.6% 나 위반했다**는 쪽에 있다. 지금 서비스가 그 상태다

## 7. 05D 착수 조건 대비

| 조건 | 상태 |
|---|---|
| 1. 승인 QA ≥ 3,000 | ❌ 사람 확정 **221건** |
| 2. holdout 분리 | ✅ 다섯 검사 통과(실데이터로 처음) |
| 3. 이중 검수 | ◐ 프로세스는 있으나 한 바퀴 못 돌았다 |
| 4. 동시 개선 증명 | ◐ **baseline 이 처음 생겼다.** `groundedness` 는 여전히 미측정 |

→ **배포 판단은 아직 못 한다**(05D §8-2 — `artifact_sha256`·`verified_at` 미기록).
다만 §12-3 이 든 기각 사유 넷 중 **2(속도)·3(12GB)는 이번 실측으로 해소되거나 뒤집혔다.**
