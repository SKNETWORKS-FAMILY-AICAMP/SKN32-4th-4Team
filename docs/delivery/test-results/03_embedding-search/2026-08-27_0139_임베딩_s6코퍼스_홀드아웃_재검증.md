# 임베딩 배포 모델 — s6 코퍼스 재구축 + holdout 재검증

- 이어지는 작업: 13_임베딩모델_선정_브리핑.md (내부 원본 참조: `../handoff/13_임베딩모델_선정_브리핑.md`) §3-3-★("배포 모델을 정하면 안 되는 이유", 5단계 요구)
- 대상: 5단계 중 **②s6 코퍼스**·**④지연·저장비용**·**⑤holdout** — 3개 완료.
  **①δ**(허용 손실폭)·**③구어체 질의**는 사람 판단·실사용자 데이터가 필요해 미해결(§4).
- 상태: **완료.** GPU 호스트(RTX 4000 SFF Ada, 20GB, `205.196.17.188:10747`)에서 실측.

## 1. 왜 지금 하나

브리핑 §5-3이 "이 평가셋은 s5 기준"이라고 명시한 한계를, §15 s6 재생성
(2026-08-26 23:20 완료, [완료보고](../02_preprocess-ocr-table/2026-08-26_2325_s6_전량재생성_S15반영_완료보고.md))
직후인 지금 메우는 게 타이밍상 가장 낫다 — 가장 최신 구조화 산출물 기준으로
재는 것이기 때문이다.

## 2. 도구 변경

- `scripts/eval/build_retrieval_set.py` — `--schema {s5,s6}`·`--seed`·`--out`·
  `--exclude-ids-file` 추가. 인자를 안 주면 기존 s5 하드코딩 동작 100% 유지
  (하위호환). `--exclude-ids-file`은 holdout이 메인셋과 안 겹치게 하려는
  용도 — content_hash 앞 16자(`id`)로 제외한다.
- `scripts/eval/bench_embedders.py` — `--set`·`--results-dir` 추가.
  안 주면 기존 `data/eval/embed_bench.json`/`embed_bench_results/` 그대로라
  **s5 결과를 덮어쓰지 않는다.**

## 7. 그래서 뭐가 바뀌었나

- **바뀐 것 없음, 더 단단해졌음.** 기존 1순위(`arctic-ko`)를 부정할 근거가
  s6·holdout 어디에도 없다. `BGE-m3-ko`가 점추정으로는 계속 앞서지만
  통계적으로 확인되지 않는 것도 s5→s6→holdout 3번 다 같다.
- **새로 닫힌 것**: 5단계 중 ②(s6 코퍼스)·④(지연·저장비용)·⑤(holdout)
  — 이번 작업으로 완료. `Qwen3-Embedding-4B`는 성능도 열세·속도도 느림·
  OOM 위험까지 있어 사실상 탈락으로 봐도 된다(조건부→탈락).
- **여전히 안 닫힌 것**: ①δ(팀이 감당할 손실폭 결정, 정책 판단)·
  ③구어체 질의(실사용자 없음 + "LLM으로 질문 지어내면 안 된다"는 원칙상
  이 세션이 혼자 만들 수 없음).

## 8. 다음 세션 제안

- **당장 배포해야 한다면**: `dragonkue/snowflake-arctic-embed-l-v2.0-ko`
  유지가 합리적이다 — 3번의 독립 측정(s5·s6·holdout)에서 한 번도 열세가
  확인된 적이 없고, `BGE-m3-ko`의 점추정 우위도 통계적으로 못 박히지
  않았다. 근거는 "통계적 승리"가 아니라 "반복 측정에서 흔들리지 않은
  1순위 유지"다.
- **δ**: 팀이 감당할 손실폭을 먼저 정하고, 그 뒤에 §5 표로 최종 판정한다
  (숫자 보고 나서 δ를 정하면 브리핑 §3-3-★가 경고한 바로 그 함정이다).
- **구어체 질의**: 팀원이 실제 있을 법한 질문 예시를 손으로 몇 개 적어
  주면(LLM이 대신 짓지 않고) 그걸로 추가 탐침을 만들 수 있다.
- **s7.1(승인 fact 850건)**: 최종 모델이 확정되면 s6 조항뿐 아니라
  이것도 같이 재임베딩해야 인덱스가 일관된다(§s6 재색인 GPU임베딩 작업
  계획과 함께 진행).

## 9. 재현

```bash
# 평가셋(로컬, GPU 불필요)
python -m scripts.eval.build_retrieval_set --schema s6 --out data/eval/embed_bench_s6.json
python -m scripts.eval.build_retrieval_set --schema s6 --seed 20260827 \
  --exclude-ids-file data/eval/embed_bench_s6.json --out data/eval/embed_bench_s6_holdout.json

# 측정(GPU)
python -m scripts.eval.bench_embedders --model <모델ID> \
  --set data/eval/embed_bench_s6.json --results-dir data/eval/embed_bench_results_s6 --purge

# 짝비교
python -m scripts.eval.bench_embedders --compare dragonkue/snowflake-arctic-embed-l-v2.0-ko \
  --task title --dtype float32 --md --results-dir data/eval/embed_bench_results_s6
```
