# S6 Arctic-ko 리랭커 5종 실측과 운영 반영

작성일: 2026-08-04 KST

## 결론

정확도 우선 운영 모델은 `Qwen/Qwen3-Reranker-4B`로 결정한다. 저지연 또는 VRAM 부족 환경의 대안은 `BAAI/bge-reranker-v2-m3`이다.

- Qwen3-Reranker-4B는 검색 가능한 314문항에서 Hit@1 `84.71%`, MRR@10 `0.9104`를 기록했다.
- dense Arctic-ko 기준선 대비 Hit@1은 `+20.06%p`, MRR@10은 `+0.1420`이다.
- BGE 대비 Hit@1은 `+6.69%p`, MRR@10은 `+0.0542`이다.
- 어려운 대체표현 98문항에서 Qwen3-Reranker-4B Hit@1은 `73.47%`, BGE는 `50.00%`였다.
- paired bootstrap 95% CI도 Qwen3-Reranker-4B 우위를 지지했다. 전체 Hit@1 차이는 `+1.59~+11.78%p`, 대체표현은 `+11.22~+35.71%p`였다.
- BGE는 top20 기준 약 `0.49초/질의`, Qwen3-Reranker-4B는 약 `1.76초/질의`에 해당하는 처리량을 보였다. 이는 배치 실측 환산값이며 온라인 p95는 별도 측정해야 한다.

## 평가 입력

- 임베딩/1차 검색: `dragonkue/snowflake-arctic-embed-l-v2.0-ko`
- 원본 청크: 145,220개
- 평가 질의: 417개
- 후보: 질의별 같은 문서 안의 dense top20
- 총 query-document pair: 8,273개
- 입력 SHA-256: `f9338edaae9a5d7ac8579888aa7ab5f45db4f6bd7926bce94261867025f1ad2f`
- gold가 top20에 존재하는 질의: 314개
- gold가 S6 delivery에 없거나 top20에 없는 질의: 103개
  - 이 중 93개는 주로 S5 평가 ID와 S6 delivery 불일치로 확인됐다.

`retrievable` 지표는 리랭커 자체의 순위 재배치 능력을 본다. `all` 지표는 후보 생성·버전 불일치까지 포함한 종단 결과다. 두 지표 중 하나만 단독으로 보고하지 않는다.

### Qwen3-Reranker-4B와 BGE의 paired 비교

- retrievable 314건: Qwen3-Reranker-4B만 Hit@1 성공 45건, BGE만 성공 24건, 동률 245건
- exclusion-alt 98건: Qwen3-Reranker-4B만 성공 34건, BGE만 성공 11건, 동률 53건
- 10,000회 paired bootstrap, seed `20260804`
  - 전체 Hit@1 차이 `+6.69%p`, 95% CI `+1.59~+11.78%p`
  - 전체 MRR 차이 `+0.0542`, 95% CI `+0.0218~+0.0869`
  - 대체표현 Hit@1 차이 `+23.47%p`, 95% CI `+11.22~+35.71%p`

Qwen3-Reranker-4B는 exclusion-own에서 BGE의 100%보다 낮은 94.12%를 기록했다. 고정 50:50 reciprocal-rank fusion은 전체 Hit@1을 85.99%로 올렸지만 대체표현 Hit@1을 72.45%로 낮추고 두 모델 상시 비용을 요구한다. 동일 평가셋 탐색 결과이므로 운영 기본값으로 채택하지 않는다.

## 무효 결과: Querit-4B

`Querit/Querit-4B` revision `7b796de...`는 현재 일반 `CrossEncoder` 경로에서 유효하게 평가되지 않았다.

- 로드 로그: `score.weight`가 체크포인트에서 초기화되지 않아 새로 무작위 초기화됐다는 경고
- 8,273개 출력 점수: 전부 `0.76025390625`
- 결과: dense 순서를 한 건도 바꾸지 못함

따라서 모델 품질이 낮다고 결론 내리지 않고 `checkpoint/scoring-adapter incompatibility`로 분류했다. 원시 JSON과 로그 근거는 보존하되 모델 순위에서는 제외했다. 공식 저장소가 올바른 scoring head/사용 예시를 제공하면 고정 revision으로 한 번 재평가한다.

## 운영 반영

- `CrossEncoderReranker`를 lazy/thread-safe 방식으로 추가했다.
- 기본 모델 설정은 Qwen3-Reranker-4B, 저지연 폴백 설정은 BGE다.
- `RAG_RERANK_ENABLED=false`가 기본이다. GPU serving 준비 뒤 명시적으로 활성화한다.
- top20, max length 768, FP16, batch 1을 Qwen3-Reranker-4B 기본값으로 기록했다.
- 점수 개수 불일치, NaN/Inf, 상수·근상수 점수는 예외로 차단한다.
- 평가 실행기는 입력 SHA, 모델 revision, dtype, 점수 범위·표준편차·tie 비율을 provenance로 남긴다.

파인튜닝은 지금 하지 않는다. zero-shot Qwen3-Reranker-4B가 충분한 개선을 보였고, 현재 93건 gold 불일치가 학습 데이터보다 먼저 해결해야 할 문제다. 운영 질의·클릭·검수 로그가 쌓인 뒤 hard negative mining으로 혼동 후보를 모으고, 그때 LoRA 또는 distillation을 검토한다.

## Claude CLI 교차검토

Claude는 다음을 독립 지적했고 반영했다.

- retrievable-only는 리랭커 능력을 보지만 쉬운 부분집합 편향이 있으므로 all 지표와 항상 병기
- 93건 gold 버전 불일치를 재매핑·이중검수
- 정확도 우선 보험 보조 업무는 Qwen3-Reranker-4B, BGE는 저지연 폴백
- 상수/저분산, finite, 입력 SHA, revision, dtype, tie, truncation 게이트 필요
- Querit 무효 판단은 타당하되 모델 자체 품질과 체크포인트/어댑터 결함을 구분
