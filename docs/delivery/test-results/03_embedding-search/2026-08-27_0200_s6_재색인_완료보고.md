## 4. ★내 실수 — GPU 를 두 프로세스가 나눠 썼다

첫 실행이 실패한 줄 알고 두 번째를 띄웠다. 원인은 `sh` 파싱이다 —

```sh
cd X && rm && nohup ... &   sleep 8; cat full.start
```

가 `(cd X && rm && nohup ...) & (sleep 8; cat full.start)` 로 갈린다.
`cd` 가 배경 서브셸 안에서만 일어나 **확인 명령이 원래 디렉터리에서 돌았고**,
파일이 「없다」고 나온 것을 실패로 읽었다.

결과: 두 프로세스가 GPU 를 나눠 6.19초/배치 → 하나 끝난 뒤 2.10초/배치.
**약 두 배 느려졌다.** 산출물 자체는 온전했다(55,203 × 1024 · 노름 전부 1.0 · 0행 없음).

★다음부터: 배경 실행 확인은 **절대경로**로 하거나 `setsid` 뒤 `ls /전체/경로/` 로 본다.
