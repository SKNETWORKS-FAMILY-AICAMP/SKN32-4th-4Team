## 4. 미해결 이슈와 다음 작업

1. `Qwen/Qwen3-Embedding-4B@4bit`는 GPU 전체 재측정이 필요하다.
   `--probes-only`로는 ranks가 생성되지 않는다.
2. fp16↔4bit 통제 비교를 계속 주장하려면 같은 GPU에서 두 정밀도를 모두 전체 재측정하는 편이 안전하다.
3. 공용 GPU 작업 전 `RULE.md §3.5`에 따라 점유를 확인해야 한다. 이번 작업에서는 원격 실행하지 않았다.
4. 스키마 실패를 해소하고 25개 주장 후보를 사람이 검토한 뒤에만 새 동결본을 승인한다.
5. 향후 결과에는 `eval_set_sha256`·`bench_code_sha256`·`result_schema_version`·측정 시각을 넣는 방안을 별도 계획으로 검토한다.
