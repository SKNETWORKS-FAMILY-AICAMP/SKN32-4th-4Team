## 6. 새로 드러난 결함

1. 동결 JSON이 현재 문서·기존 생성기 2개와 다르고, 확대 대상 4개 키는 동결본에 없다.
2. `Qwen/Qwen3-Embedding-4B@4bit` 결과는 `title`·`tail`·`exclusion` 및 ranks가 없는 구형 스키마다.
   정상 예외가 아니다. 그래서 문서의 4bit 행에서 면책 MRR가 `—`이며 ranks 재계산도 불가능하다.
3. 브리핑에 적힌 생성 명령 중 `--report --md`, `--report --md --dtype 4bit`,
   `--prefixes --md`는 stdout을 만든 뒤에도 CLI가 `--model`을 요구하여 종료 코드 2와 stderr를 낸다.
   `--repro --md`만 종료 코드 0이다.
4. 단정 어휘 22곳은 전부 출력됐지만 사람 검토 후보이지, 이번 도구만으로 확정한 문서 결함은 아니다.
5. 확대된 본문 숫자(145/60/16, 후보 9, 4bit 전후값, GPU 조건)에서는 불일치가 새로 나오지 않았다.
6. 전체 테스트 중간 실행에서는 loose legacy HTML/JS 2개로 `test_arch_004`가 실패했지만,
   병행 트랙 정리 뒤 최종 실행은 전부 통과했다. 이 작업은 그 파일을 수정·삭제하지 않았다.

- `bench_embedders.main()`의 report/prefix 분기 뒤 반환 누락은 별도 도구 수정 범위로 고쳐야 한다.
- 단정 후보 22곳은 문장별 사람 검토가 필요하다. 브리핑 문서는 이번 작업 범위에서 수정하지 않았다.
