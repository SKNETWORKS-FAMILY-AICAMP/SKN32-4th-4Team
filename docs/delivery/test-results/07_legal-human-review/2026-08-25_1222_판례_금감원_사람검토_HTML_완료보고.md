## 무엇을 만들었나

비전공자도 사건 원문과 AI가 정리한 쟁점·사실·결론을 한 화면에서 비교할 수 있는 오프라인 검토 화면을 만들었다. 서버에 접속하지 않고 HTML 파일 하나를 브라우저로 열어 사용한다.

사람은 각 사건을 읽은 뒤 아래 셋 중 하나를 고른다.

- `맞음`: AI 설명과 결론이 원문 뜻과 같다.
- `수정 필요`: 자료는 쓸 수 있지만 AI 설명이나 결론이 틀렸다. 메모에 올바른 내용과 근거를 적는다.
- `제외`: 원문이 부족하거나 우리 판단 자료로 쓰기 어렵다. 메모에 이유를 적는다.

## 화면 기능

- 사건번호·쟁점·결론 검색
- 법원/금감원 출처 필터
- 미검토/맞음/수정 필요/제외/메모 미완료 상태 필터
- 전체 진행률과 다음 미검토 사건 이동
- 선택과 메모의 브라우저 자동 저장
- 다른 브라우저에서 이어 하기 위한 기존 JSON 불러오기
- 기존 반영 도구가 읽는 `human_review_queue.json` 내려받기
- 검토자 이름을 넣은 반영 명령 복사
- 휴대전화 폭과 인쇄 화면 대응

## 사용 순서

1. `docs/review/legal_case_human_review_20260825.html`을 더블클릭해 브라우저로 연다.
2. 왼쪽 목록에서 사건을 고르고 원문과 AI 정리를 비교한다.
3. `맞음`, `수정 필요`, `제외` 중 하나를 누른다.
4. `수정 필요`나 `제외`는 반드시 메모를 적는다.
5. 검토를 마치면 `현재까지 JSON 내려받기`를 누른다.
6. 내려받은 파일을 `data/legal/human_review_queue.json` 위치에 둔다.
7. 화면 위쪽에 검토자 이름을 적고 `반영 명령 복사`를 눌러 명령을 실행한다.

## 남은 확인

현재 세션에 연결 가능한 브라우저가 없어서 실제 버튼 클릭과 내려받기는 자동 브라우저로 확인하지 못했다. 이 사실을 완료로 위장하지 않는다. 브라우저가 연결되는 세션에서 다음 네 가지만 최종 확인하면 된다.

3. 출처·상태 필터가 맞게 줄어든다.
4. 내려받은 JSON을 다시 불러올 수 있다.

코드와 데이터 형식에 대한 자동 시험은 위와 같이 모두 통과했다.
