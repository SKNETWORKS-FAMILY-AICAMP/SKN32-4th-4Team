## 한눈에 보는 결과

5파트에 배정된 23건을 원문과 현재 AI 정리 내용으로 먼저 대조했다. 사람이 다시 볼 필요가 없는 정상 후보 14건은 후속 화면에서 접어 두었고, 실제 결정이 필요한 9건만 별도 HTML에 담았다.

| 구분 | 건수 | 뜻 |
|---|---:|---|
| `codex_confirmed` | 14 | 원문과 현재 정리 내용이 일치하는 정상 후보 |
| `codex_corrected` | 7 | 잘림·복사 실패·분류 오류가 있어 Codex 수정안을 작성한 건 |

`codex_confirmed`는 사람 검증 완료를 뜻하지 않는다. 최종 정답셋에 `human` 상태를 붙이려면 사람이 승인한 기록이 별도로 필요하다.

## 제공 파일

- 사람 확인 화면: `docs/review/part5_human_followup_20260825.html`
- 전체 검토 장부: `docs/review/part5_codex_review_20260825.json`
- 재생성 코드: `scripts/legal/build_part5_followup.py`
- 회귀 시험: `tests/test_part5_followup.py`

기존에 팀원에게 배포한 5개 검토 파일은 수정하거나 다시 압축하지 않았다. 이번 HTML은 5파트 담당자의 후속 확인만 줄이기 위한 별도 파일이다.

## 화면 사용법

1. HTML을 더블클릭해 연다.
2. 왼쪽의 원문과 현재 AI 내용을 읽는다.
3. 오른쪽의 Codex 수정안과 질문을 확인한다.
4. `수정안 승인`, `현재 내용 유지`, `추가 재검토`, `자료 제외` 중 하나를 선택한다.
5. 필요한 설명을 메모에 적는다.
6. 9건을 결정한 뒤 `결정 JSON 내려받기`를 누른다.

선택 내용은 해당 브라우저에 자동 저장된다. 미결정 건이 남은 상태로 내보내려 하면 경고가 뜨며, 내보낸 JSON에는 완료 여부가 함께 기록된다.
