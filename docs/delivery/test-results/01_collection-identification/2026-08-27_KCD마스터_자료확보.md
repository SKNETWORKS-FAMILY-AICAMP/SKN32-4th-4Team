# KCD(질병분류) 마스터 자료 확보 — 완료보고

- 계기: DB 잔여작업 정리 (내부 원본 참조: `2026-08-27_0600_DB잔여작업_정리와_KCD사전_부재.md`) §4 —
  `core.kcd_code`가 0행이라 판정 원장(`PRECHECK_PERSISTENCE=postgres`)이 막혀
  있고, 원인은 "코드→질병명 사전을 우리가 갖고 있지 않다"였다. 팀 결정
  ("통계청 KCD 공공데이터 조사 시도" + "다운까지 받아")에 따라 자료를 찾아
  실제로 내려받았다.
- 상태: **자료 확보 완료.** ★DB 적재는 안 했다 — "DB는 다른 곳에서 작업
  중"이라는 이번 세션 경계 때문에 원재료만 갖다 둔다.

(`publicDataPk=15067467`, `dataNm=건강보험심사평가원_상병마스터_20250930`)를
다운로드 API를 직접 재현해 받았다(브라우저 JS 소스 역추적으로 정확한
엔드포인트 확인 — `check-limit.json`으로 캡차 필요 여부 확인 후
`fileDownload.do`로 실제 파일 요청).

- 저장 위치: `data/raw/kcd/` (내부 원본 참조: `../../data/raw/kcd/`)
  - `5723ccce218d_건강보험심사평가원_상병마스터_20250930.csv` (원본, CP949)
  - `5723ccce218d_건강보험심사평가원_상병마스터_20250930.utf8.csv` (UTF-8 변환)

## 2. 구조 확인

| 항목 | 값 |
|---|---:|
| 전체 행수 | 47,798 (+헤더 1) |
| 고유 상병기호 수 | **21,299** — 막힌 리포트 (내부 원본 참조: `2026-08-27_0600_DB잔여작업_정리와_KCD사전_부재.md`)가 말한 "약 2만 항목"과 일치 |
| 컬럼 | 상병기호, 한글명, 영문명, 완전코드구분, 주상병사용구분, 법정감염병구분, 성별구분, 상한연령, 하한연령, 양한방구분 |

`core.kcd_code`가 요구하는 `code`(→상병기호)·`name_ko`(NOT NULL,→한글명)를
그대로 채울 수 있는 형태다. 단, 한 상병기호에 이명(異名)이 여러 개 붙는
행이 있어(예: A000이 2행) 47,798 → 21,299로 다대일이다 — 적재 시 대표
명칭 선정 규칙이 필요하다(이 세션에서 정하지 않음).

## 3. 안 한 것 (다음 사람 몫)

1. **`core.kcd_version`/`core.kcd_code` 적재 자체.** "DB는 다른 곳에서
   작업 중" 경계 때문에 이 세션은 손대지 않았다.
2. **차수(`version_label`) 결정.** 이 자료는 `_20250930` 스냅샷 하나뿐이다
   — 과거 사고일에 적용할 다른 차수가 필요한지는 확인 안 함.
3. **이명 다대일 처리 규칙.** 상병기호당 여러 한글명 중 대표값을 어떻게
   고를지(완전코드구분 `N` 우선? 최신 행 우선?) 정하지 않았다.
4. **`kcd_ranges.py`가 뽑은 범위(525개)와의 정합성 검증.** 이 마스터의
   코드가 그 범위들을 실제로 커버하는지는 확인 안 함.

```bash
curl -sS -X POST 'https://www.data.go.kr/cmm/cmm/check-limit.json' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data 'atchFileId=FILE_000000003511734&fileDetailSn=1'
# {"needCaptcha":false} 면 아래 진행

# 2) 실제 다운로드
curl -sS -L 'https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003511734&fileDetailSn=1&dataNm=%EA%B1%B4%EA%B0%95%EB%B3%B4%ED%97%98%EC%8B%AC%EC%82%AC%ED%8F%89%EA%B0%80%EC%9B%90_%EC%83%81%EB%B3%91%EB%A7%88%EC%8A%A4%ED%84%B0_20250930' \
  -o kcd_master.csv

# 3) 인코딩 변환(원본은 CP949)
iconv -f CP949 -t UTF-8//TRANSLIT kcd_master.csv > kcd_master_utf8.csv
```
