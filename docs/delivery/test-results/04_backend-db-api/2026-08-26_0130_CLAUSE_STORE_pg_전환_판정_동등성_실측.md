# `CLAUSE_STORE=pg` 전환 판정 — 동등성 실측

2026-08-26

---

## 1. 물어본 것

`CLAUSE_STORE` 환경변수 하나로 조항 저장소가 갈린다(`file` ↔ `pg`).
**같은 질문에 같은 판정을 내는가?**

기존 시험(`tests/test_clause_store_parity.py`)은 4건 통과하지만, 그것만으로는
**양쪽이 다 기권해서 통과한 것**일 수 있다. 그래서 따로 셌다.

## 2. 실측 (읽기 전용)

확정 판본 1,296개에서 **무작위 25문서** × 질병기호 4개 = **100건**.
`F20.0`(조현병) · `S72.0`(대퇴골 골절) · `K80.2`(담낭결석) · `O00.0`(자궁외임신).

| | `file` | `pg` |
|---|---:|---:|
| `NEEDS_EXPERT` (기권) | 58 | 58 |
| `UNLIKELY` (면책) | **26** | **26** |
| `NEEDS_DOCUMENTS` (예외) | **16** | **16** |
| **인용 총합** | **68** | **68** |
| 결론+인용수 불일치 | — | **0건** |

★**공허한 통과가 아니다.** 100건 중 **42건이 실제 판정**이고, 근거 조항을 68건 댔다.
  그 42건에서 양쪽이 결론도 인용 개수도 정확히 같았다.

## 3. 결론 — 판정 동등성은 **확인됐다**

`CLAUSE_STORE=pg` 로 바꿔도 판정이 달라지지 않는다.

★다만 **전환해도 좋다**는 말은 아니다. 남은 것 —

| 확인 필요 | 왜 |
|---|---|
| **성능** | 파일은 지문 캐시로 1,367줄을 재사용한다. PG 는 매 요청 질의다. 지연을 안 쟀다 |
| **커버리지** | 표본 25문서다. 전량 1,296문서로 돌린 값이 아니다 |
| **인용 검증** | `occurrence_id` 가 채워져야 인용 검증이 돈다. 2026-08-25 에 고쳤지만 전량 재확인 안 함 |
| **개념 스키마** | 이건 조항 저장소와 별개 문제다 → 리포트 (내부 원본 참조: `2026-08-26_0100_개념스키마가_비어_있어_근거있는_판정이_저장되지_않는다.md`) |

## 4. 표본이 작다는 것을 적어 둔다

25문서는 **작다**(전체의 1.9%). 다만 「양쪽이 다 기권해서 통과」를 배제하는 목적에는
충분하다 — 실제 판정 42건에서 불일치 0을 봤기 때문이다.
전환을 확정하려면 전량으로 다시 돌린다.
