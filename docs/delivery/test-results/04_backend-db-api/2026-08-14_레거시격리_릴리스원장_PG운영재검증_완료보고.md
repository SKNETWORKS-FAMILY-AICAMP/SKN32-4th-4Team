## 2. 승인 릴리스 단일 원장

- `app/core/release.py`의 `AcceptedRelease`가 `config/accepted_extraction.json`을 단일 소스로 사용
- `clause_tag`에서 `index_generation`을 파생하며 별도 세대 상수를 두지 않음
- file/PG/index 경로가 릴리스 포인터와 embed profile을 읽음

- `release.current().ensure_ready()`가 승인된 조항 산출물 1,367개를 확인
- 모델 확정 및 shadow index 승격은 별도 평가 게이트가 남아 있어 완료 처리하지 않음
