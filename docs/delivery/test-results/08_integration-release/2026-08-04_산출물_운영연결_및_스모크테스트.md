## 프로젝트 연결 방식

`config/accepted_extraction.json`이 두 포인터를 가진다.

- `supplemental_facts`: 사람 승인 S7.1 설정. 850 occurrence가 활성 pgvector 인덱스에 적재돼 실제 검색에 참여한다.
- `candidate_fact_registry`: B8/F4 shadow 입력. 애플리케이션 readiness가 파일 경로, SHA-256, 행 수, fact 수, 승인·serving·citation 차단 상태를 매번 검증한다.

후보 registry는 fail-closed다. 파일 손상, 해시 불일치, 행/fact 수 불일치 또는 후보 행 하나라도 승인·serving 가능 상태로 바뀌면 readiness가 실패한다. 후보를 단순히 디스크에 보관만 하던 이전 상태와 달리 프로젝트 입력으로 연결됐지만, 사람 승인 전 답변 근거로 사용되지는 않는다.
