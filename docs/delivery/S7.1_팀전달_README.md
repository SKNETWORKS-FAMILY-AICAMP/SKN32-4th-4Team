# S7.1 OCR·표 복원 팀 전달 패키지

## 핵심 상태

- 활성 릴리스: `r2026-08-04-clause-s7.1-arctic-ko-ocr-approved`
- 사람 승인 OCR facts: 850 occurrence / 75 chunks / 179 documents
- 임베딩: `dragonkue/snowflake-arctic-embed-l-v2.0-ko`
- 리랭커: `Qwen/Qwen3-Reranker-4B`
- B8/F4 후보: 8,622 facts, 모두 shadow-only

## 적용

저장소 루트에서 압축을 풀면 원래 상대 경로로 배치된다.

1. `config/accepted_extraction.json`의 활성 release와 두 포인터를 확인한다.
2. 승인 OCR DB 적재가 필요한 환경에서는 `python -m scripts.index.load_s7_1_approved_facts`를 실행한다.
3. `python -m pytest tests/test_candidate_fact_registry.py tests/test_s7_1_human_approval.py tests/test_s7_candidate_isolation.py -q`를 실행한다.
4. API 기동 후 `/api/health/ready`에서 `candidate_fact_sources.ready=true`와 `clause_index.ready=true`를 확인한다.

## 안전 경계

`data/candidates/s7_disability_rates/`와 `data/candidates/s7_delayed_payment_interest/`는 사람 승인 전 후보이다. `config/candidate_fact_sources.json`이 해시·행·fact 수와 `shadow_only` 계약을 검증한다. 이 파일을 승인 DB 적재나 citation에 직접 사용하지 않는다.
