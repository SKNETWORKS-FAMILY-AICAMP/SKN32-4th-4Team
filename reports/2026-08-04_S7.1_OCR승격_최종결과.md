## 결론

사람이 검수한 S7 OCR 29패턴 중 `approve` 24패턴·850 facts만 검색 대상으로 승격했다. `fix` 5패턴·216 facts는 계속 격리했다. 승인 facts는 850 source occurrence와 원문 표기 차이를 보존한 75개 고유 청크로 물질화했고, Arctic-ko 증분 임베딩 후 기존 145,220청크와 검색 시점에 결합했다.

417개 기존 평가질의의 top20을 다시 발행한 결과 승인 OCR fact가 6질의·23 candidate pair에 실제 유입됐다. Qwen3-Reranker-4B는 총 8,285쌍을 채점했고 membership·유한값·비상수 점수·인용 locator 게이트를 모두 통과했다. 기존 평가셋의 Hit@1과 MRR@10은 accepted 기준선과 동일해 회귀가 없다.

이 산출물은 더 이상 “OCR 미포함 기준선”이 아니다. 다만 현재 평가셋은 기존 조항 검색 정답셋이라 새 자기부담금 사실 자체의 정답률을 직접 재는 독립 holdout은 아니다. 여기서 확인한 것은 승인 fact의 실제 검색/리랭크 유입과 기존 검색 품질 비회귀다.

## CPU 후속 작업: B7·B8·F4·검색 지연

### B7 외부 표 라벨 계보

`_3rd_project_4`의 현재 파일은 가져올 당시와 바이트 해시가 다르지만, 중복 제거한 59개 `(label, sha12, page)` 의미 집합은 완전히 같다. 59/59가 현재 s5 1,367문서에 존재하며 문서·페이지·SHA 접두 누락은 모두 0이다. 따라서 판본 불일치가 아니라 파일 재직렬화·중복 행 변화이며 기존 라벨은 유효하다.

### B8 장해분류표 지급률

S5 전량 1,367문서·162,678쪽·좌표표 110,234개를 스캔했다. 좌표 열에서 잘린 설명을 사용하지 않고 페이지 읽기순서 본문의 완전한 `1)..N)` 설명 목록과 뒤따르는 N개 지급률 벡터를 복원했다.

| 항목 | 결과 |
|---|---:|
| `장해의 분류` + `지급률` 헤더 페이지 | 2,088 |
| 엄격 불변식 통과 | 1,297표 |
| candidate facts | 8,586 |
| 기존 게이트에서 차단됐던 표 | 1,281 |
| 정확한 설명·지급률 패턴 | 26 |

게이트는 헤더 쌍, 2개 이상 항목, 1..N 연속 번호, 빈 설명 없음, 항목 수=지급률 수, 지급률 1~100을 모두 요구한다. 과거 추정 8,859쌍보다 273쌍 적은 이유는 이 추가 안전조건이다. 26개 고유 패턴 전체에 대해 대표 원문 위치를 담은 검수 큐를 만들었다. 사람 짝 정확도 승인 전까지 전부 candidate-only이며 serving·citation은 차단한다.
